# Charles Proxy — Free Offline Installer

![Category](https://img.shields.io/badge/HTTP_Debugger-blue?style=flat-square)

## About

Charles Proxy is an HTTP proxy and monitor for Windows, macOS, and Linux that enables developers to view HTTP and SSL traffic between machines. Inspect API calls, debug web service communication, throttle bandwidth to simulate slow connections, and record sessions for replay. Charles is an established tool in mobile and web development workflows for network debugging.

## Common Problems & Limitations

- **Commercial License** — Paid license required
- **Interface Dated** — Java Swing interface less polished than modern alternatives
- **Setup Complexity** — SSL proxying requires certificate installation
- **Mobile Setup** — Debugging mobile devices requires manual proxy configuration
